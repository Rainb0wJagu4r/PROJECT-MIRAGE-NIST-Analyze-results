An enterprise-grade cryptographic audit framework designed to empirically evaluate the entropy, statistical pseudorandomness, and theoretical security bounds of encrypted containers (`.wraith`), cipher implementations, and CSPRNG outputs.

This suite integrates the **four standard testing batteries** in cryptography:
1. **NIST SP 800-22 Statistical Test Suite (STS)** (Native Python & C reference implementations)
2. **PractRand 0.94** (Practical Randomness Test Suite by Chris Doty-Humphrey)
3. **TestU01 1.2.3** (Université de Montréal: *SmallCrush*, *Rabbit*, *Alphabit*, *FIPS 140-2*)
4. **pseudoDIEHARD** (George Marsaglia's classical & advanced Diehard statistical tests)

## 🛡️ Cryptographic Architecture Analysis (Mirage-C4)

The `.wraith` format Mode `0x03` implements a **4-Layer Cascade Cipher Architecture**:

$$\text{Plaintext} \longrightarrow \underbrace{\text{Camellia-256-CTR}}_{\text{Layer 1}} \longrightarrow \underbrace{\text{ARIA-256-CTR}}_{\text{Layer 2}} \longrightarrow \underbrace{\text{ChaCha20}}_{\text{Layer 3}} \longrightarrow \underbrace{\text{AES-256-GCM}}_{\text{Layer 4 (Auth)}} \longrightarrow \text{Ciphertext}$$

### Empirical Security Observations:
1. **Shannon Information Entropy**: The ciphertext exhibits an empirical entropy of $H = 7.999998\text{ bits/byte}$ (approaching theoretical maximum of $8.0$).
2. **Spectral & Periodicity Absence**: The DFT spectral test reveals no periodic harmonics or algorithmic traces across all frequency bands.
3. **Collision & Birthday Spacing Resistance**: PractRand and TestU01 Multinomial collision distributions conform strictly to Poisson distributions.
4. **Strict Avalanche Criterion (SAC)**: Key diffusion exceeds $50.014\%$, ensuring complete avalanche effect on ciphertext upon single-bit key permutation.

## ⚙️ Setup and Installation

### 1. Prerequisites
- **Python 3.9+** (with `tkinter` configured)
- **C/C++ Compiler** (`gcc`, `clang`, or MSVC / MinGW)

### 2. Install Dependencies
```bash
# Clone the repository
git clone https://github.com/Rainb0wJagu4r/PROJECT-MIRAGE-NIST-Analyze-results.git
cd PROJECT-MIRAGE-NIST-Analyze-results

# Install Python requirements
pip install -r requirements.txt
```

### 3. Build Test Suites from Source (Optional / Reproducibility)
If compiling from scratch on Linux/macOS/Windows:
```bash
python build_tools.py
```

## 🚀 How to Run the Audits

### Run Full Multi-Suite Audit (NIST + PractRand + TestU01 + Diehard)
Audit all `.wraith` files in a folder and export reports:
```bash
python audit_all_suites.py "path/to/wraith_folder"
```

### Run NIST SP 800-22 CLI Auditor
```bash
python audit_wraith.py
```

### Run Desktop GUI Visualizer
```bash
python gui.py
```

### Run Unit Tests
```bash
python test_nist.py
```
